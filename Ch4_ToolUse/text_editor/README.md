# Text Editor プロジェクト

このプロジェクトは、円周率（π）を計算するPythonモジュールとそのテストコードで構成されています。

## ファイル構成

- `main.py`: 円周率計算のメイン機能を提供
- `test.py`: main.pyの関数をテストするテストコード

## main.py

### 関数一覧

#### `greeting()`
簡単な挨拶メッセージ "Hi there" を出力する関数です。

#### `calculate_pi(digits=5)`
ライプニッツの公式を使用して円周率を計算する関数です。

**ライプニッツの公式:**
```
π = 4 * (1 - 1/3 + 1/5 - 1/7 + 1/9 - ...)
```

**パラメータ:**
- `digits` (int): 小数点以下の桁数（デフォルト: 5）

**戻り値:**
- float: 計算された円周率の値を指定された桁数に丸めた値

**実装の詳細:**
- 反復回数: 1,000,000回（精度を高めるため）
- 計算方法: ライプニッツの公式を用いた級数展開
- 結果は指定された桁数に四捨五入されます

## test.py

円周率計算関数のテストを実行するモジュールです。

### テスト関数一覧

#### `test_calculate_pi()`
`calculate_pi()`関数の基本的なテストを実行します。

**テスト内容:**
- 小数点以下5桁で円周率を計算
- `math.pi`の値と比較
- 誤差を計算して表示
- 計算結果が正しいかを検証

**出力:**
- 計算結果
- 実際の値（math.pi）
- 誤差
- テスト成功/失敗の判定

#### `test_different_digits()`
異なる桁数（1〜5桁）で円周率計算をテストします。

**テスト内容:**
- 1桁、2桁、3桁、4桁、5桁の各桁数で計算を実行
- 各桁数での計算結果と期待値を比較
- 各テストの成功/失敗を表示

## 使用方法

### main.pyの使用例

```python
from main import calculate_pi, greeting

# 挨拶を表示
greeting()

# 円周率を計算（デフォルト: 小数点以下5桁）
pi = calculate_pi()
print(f"π = {pi}")

# 異なる桁数で計算
pi_3 = calculate_pi(3)
print(f"π (3桁) = {pi_3}")
```

### テストの実行

```bash
python test.py
```

**実行すると表示される内容:**
1. 基本的な円周率計算のテスト結果
2. 異なる桁数でのテスト結果（1〜5桁）
3. 追加情報（小数点以下5桁の円周率）

## 注意事項

- ライプニッツの公式は収束が遅いため、高精度な計算には多くの反復が必要です
- 現在の実装では1,000,000回の反復により、小数点以下5桁程度の精度が得られます
- より高い精度が必要な場合は、反復回数を増やすか、他のアルゴリズム（例: マチンの公式）の使用を検討してください
